# 导出失败可见性与单题隔离

## 处理规则

- 任务失败原因先写入 SQLite 再更新任务状态；日志列改为 TEXT，不再因为超过 200 字符被 Exposed 拒绝。
- 不可见的 `U+200E` / `U+200F` 方向标记直接丢弃；真实 RTL 文本仍按不支持处理。
- 整组题目都因内容不支持被跳过时，只跳过该题型分组，其它分组继续出包。
- 单题的答案解码或浏览器截图错误，在同组还有成功题目时跳过该题并记录 ID 与原因；整组都失败时按原错误上抛。
- 局部截图失败换一次干净会话重试后再判定。
- 纯平移不再套 `transform`，改用截图 `clip` 起点对齐。`transform` 会让 `#pdf-asset` 成为包含块，尺寸按百分比计算的绝对定位图片会随之塌成 0×0（实测 560×9 的公式图变 0 盒，整题被判失败）。只有需要缩小时才套 `transform`，此时仍做几何校验。
- 局部截图的几何校验先让「未变换」和「已变换」两种状态各自连续两帧测量一致再比较；盒子数量变化时改比并集包围盒，只有覆盖区域映射不上才判失败。这类漂移通常是图片解码或字体替换滞后，不再直接牺牲一道题。
- 页脚注明实际导出数：有跳过时显示「CCTR · 题库 · 实际导出 18/19 题」，全部导出时保持「CCTR · 题库」；标题行仍写匹配总数。
